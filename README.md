# Scholar Agent Feed

Public, machine-readable input for a daily research briefing. A private GitHub
Actions workflow refreshes this repository automatically.

Published files:

- `latest/date.txt`: feed date in `YYYY-MM-DD` format
- `latest/report.md`: generated topic overview with the private keyword line removed
- `latest/papers.md`: complete index of publicly sourced paper metadata

This repository intentionally contains no source code, email bodies, account
details, OAuth files, passwords, or GitHub Actions secrets.
